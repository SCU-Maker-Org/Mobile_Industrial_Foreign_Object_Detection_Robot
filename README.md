# 移动式工业异物检测机器人（履带式）

面向"机器人异物检测专项赛"的履带式自主巡检机器人。机器人在模拟核电站室内巡检环境中完全自主运行，完成对工具类、零件类、杂物类和泄漏物类异物的检测，并提交结构化检测报告。

## 机器人平台

- **底盘形式**：履带式，适应室内复杂地面与局部暗区环境
- **运行方式**：完全自主巡检，无需人工干预
- **导航能力**：支持自主导航与建图，可在赛前基准扫描阶段对场地建模
- **感知传感器**：配备 RGB 相机，可选配深度相机、热成像仪等
- **视觉检测**：基于 YOLO 的异物检测，支持双目视觉进行深度感知与三维定位

## 核心功能

| 功能 | 说明 |
|------|------|
| 自主建图与导航 | 赛前对基准场景建模，比赛中自主规划巡检路径 |
| 异物检出 | 检测工具类、零件类、杂物类、泄漏物类异物 |
| 异物分类 | 按工具类、零件类、杂物类、泄漏物类四类输出 |
| 异物定位 | 输出异物平面位置坐标，支持厘米级定位 |
| 误报控制 | 区分真实异物与设备、管道、地面纹理、阴影等背景干扰 |
| 检测报告 | 输出异物编号、类别、位置坐标、置信度和检测时间 |
| 光照适应 | 适应正常照明与局部暗区两种光照条件 |
| 遮挡适应 | 应对设备柜、管道阀门、电缆槽、基座和遮挡板形成的遮挡关系 |
